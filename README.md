# 远程文本监视器（RemoteTxtViewer）

**881 KB 单文件 Windows 原生小工具**：通过 SSH/SFTP 连到服务器，常驻显示某个 txt 文件的最新内容，
文件一变就自动刷新、新增行标黄，并把每次变更记进右侧时间线（保留 24 小时），可回看任意时刻、
可收藏存档。

不装 .NET、不装 Python、不装浏览器内核 —— 用的是 Windows 自带的 .NET Framework 4.8，双击即开。

---

## 快速开始

1. 双击桌面「远程文本监视器」
2. 第一次打开自动弹「连接设置」：

   | 字段 | 例子 | 说明 |
   |---|---|---|
   | 主机地址 | `192.168.1.100` | 服务器 IP 或域名 |
   | 端口 | `22` | SSH 端口 |
   | 用户名 | `root` | 登录账号 |
   | 认证方式 | 密码 / 私钥文件 | 私钥支持 OpenSSH 格式，可带口令 |
   | 远程文件 | `/var/log/app.log` | 要监视的文件；可点「浏览...」在服务器上选 |
   | 刷新间隔 | `2 秒` | 1~60 秒，先比对大小+修改时间，没变不下载 |
   | 文件编码 | 自动识别 | 自动区分 UTF-8 / GBK |

3. 点「测试连接」→ 成功后点「保存」。之后每次打开就直接看到内容。

### 状态栏

| 位置 | 含义 |
|---|---|
| `● 已连接` | 绿=正常 / 红=连接失败（鼠标悬停看原因）/ 橙=`◀ 历史 09:40:39 · 点此返回实时` |
| `刷新 09:44:15` | 本地最后一次轮询的时间 |
| `更改 09:41:34` | **服务器上这个文件最后一次被修改的时间**（鼠标悬停看完整日期和编码） |
| `215 B · 5 行` | 文件大小和行数 |
| `▲ 新增 3 行` | 本次刷新新增了几行；`内容已变化` 表示不是纯追加（文件被重写/截断） |
| `★ 已收藏：xxx` | 刚才收藏成功的提示 |

### 工具栏

- **自动刷新**：按下（浅蓝）表示开启
- **跟随末尾**：新内容出现时自动滚到最后一行；关掉则你往上翻看时不会被强行拉回底部
- **自动换行**：长行折行；关掉保留横向滚动条（看日志通常关掉更整齐）
- **时间线**：显示/隐藏右侧面板
- **收藏**：把当前显示的内容存进收藏夹
- **收藏夹**：打开收藏列表
- **A- / A+**：调整正文字号

## 三个新功能怎么用

### 1. 变更时间线（右侧面板）

每次检测到内容变化，就把当时的**完整快照**记一条，显示在右侧：

- `09:41:35  +3行` —— 那个时刻新增了 3 行
- `09:41:11  初始 2行` —— 程序第一次连上时文件的样子
- `内容变化` —— 文件被重写而不是追加

**只看最近 24 小时**，更早的自动清理；同时限制最多 2000 条 / 32 MB。

点击任一条 → 正文切到那一刻的内容（背景变淡黄、状态栏变橙），再点「返回实时」或按 `Esc` 回到最新。

> 新内容到来时，如果你正在看历史，正文**不会**被强制跳走 —— 只有点「返回实时」才回到最新。

### 2. 收藏

看到关键内容（比如订单失败现场、报警前后几行）：

1. 点「收藏」（或 `Ctrl + D`）
2. 名称默认是当前时间，可以直接改，比如「订单 1003 超时现场」
3. 确定 → 状态栏提示 `★ 已收藏`

收藏的内容**不会过期**，随时可以在收藏夹里找回来。

### 3. 收藏夹

点「收藏夹」（或 `Ctrl + B`）：

- 左边列表：名称 / 收藏时间 / 行数
- 右边预览：完整内容
- 底部：`在主窗口查看`、`重命名`、`删除`、`另存为...`

## 数据存在哪

```
%APPDATA%\RemoteTxtViewer\
├─ config.ini                 连接配置（密码用 Windows DPAPI 加密）
├─ history\                   变更时间线
│   ├─ index.tsv              索引
│   └─ c_<时间戳>.txt         每次变更的完整快照
└─ favorites\                 收藏夹（不会自动清理）
    ├─ index.tsv              索引（名称、时间、来源、行数）
    └─ f_<时间戳>.txt         收藏的完整内容
```

- **密码和私钥口令用 Windows DPAPI 加密**，只有当前 Windows 用户 + 这台电脑能解开。
  拷给别人、同步到网盘、换电脑都解不开。代价是换电脑/换账号要重填一次密码。
- 历史快照 24 小时自动清理；收藏永久保留（想删就在收藏夹里删）。
- 想彻底清空：关掉程序后删掉对应目录即可。

## 安全：主机指纹校验

第一次连接某台服务器时，程序会记下它的 SSH 主机密钥指纹（SHA256）存进 `config.ini`。
**以后每次连接都会比对**：

- 一致 → 正常连接，无感知
- 不一致 → 拒绝连接，状态栏红字提示：
  `服务器指纹不符！已记录 a1b2…，本次 c3d4… —— 可能是中间人攻击；若服务器重装过系统，请在设置里点「重置主机指纹」`

这是为了防止内网里有人冒充你的服务器（ARP/DNS 欺骗等中间人攻击），作用等同于 `ssh` 首次连接时问的 `yes/no`。

**什么时候需要点「重置主机指纹」**（设置对话框左下角）：
- 服务器确实重装过系统
- 服务器换了 SSH 主机密钥
- 确认服务器 IP 被重新分配给另一台机器

其他情况看到"指纹不符"请先当成安全事件处理，别急着重置。

## 常见状态与处理

| 状态栏提示 | 处理 |
|---|---|
| 认证失败 | 用户名/密码错了，或私钥不对 |
| 远程路径不存在 | 路径写错，用「浏览...」重新选 |
| 连接超时 / 网络不可达 | 没连上服务器所在网络（VPN？）或防火墙拦了端口 |
| 端口被拒绝 | SSH 服务没启动，或端口不是 22 |
| 权限不足 | 该账号无权读这个文件 |
| 服务器指纹不符 | 见上一节 |

断线不会卡死：每次轮询都会自动重连，服务器恢复后状态栏自己变回绿色。

## 源码与重新编译

```
RemoteTxtViewer\   （本项目根目录）
├─ RemoteTxtViewer.exe     编译产物（单文件，桌面快捷方式指向它）
├─ build.bat               双击重新编译（用 Windows 自带 csc.exe，不需要 Visual Studio）
├─ app.ico                 图标
├─ src\
│   ├─ Program.cs          入口 + 从 exe 内部加载 SSH 库
│   ├─ MainForm.cs         主窗口、自动刷新、增量高亮、时间线、历史视图
│   ├─ ChangeLog.cs        变更历史（24 小时滚动 + 容量上限）
│   ├─ FavoritesStore.cs   收藏夹存储
│   ├─ FavoritesForm.cs    收藏夹窗口
│   ├─ PromptForm.cs       命名输入框
│   ├─ SettingsForm.cs     连接设置（含「重置主机指纹」）
│   ├─ RemotePickerForm.cs 远程文件浏览
│   ├─ SftpFetcher.cs      SFTP 读取 + 编码识别 + 主机指纹校验
│   └─ AppConfig.cs        配置持久化 + DPAPI 加密
├─ lib\pkg\lib\net40\Renci.SshNet.dll   SSH 库（编译时嵌入 exe）
└─ tools\                  图标生成、测试用 SFTP 服务器、自动化测试与 UI 探测工具
```

改完源码双击 `build.bat` 即可。
