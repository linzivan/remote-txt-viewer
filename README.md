# 远程文本监视器（RemoteTxtViewer）

**单文件 Windows 原生小工具**：通过 SSH/SFTP 连到服务器，常驻显示某个 txt 文件的最新内容，
文件一变就自动刷新、新增行标黄，并把每次变更记进右侧时间线（保留 24 小时），可回看任意时刻、
可收藏存档。**也可以直接编辑并安全写回服务器**（带冲突保护），适合在几台电脑之间同步同一份笔记。

不装 .NET、不装 Python、不装浏览器内核 —— 用的是 Windows 自带的 .NET Framework 4.8，双击即开。

---

## 多文件监控（标签页）

**一个窗口只连一台服务器**，标签只是这台服务器上的不同文件。所以服务器连接（主机、端口、
账号、密码/密钥）全局只有一份，填一次就够了；新建标签时只需选文件。

顶部是一排标签，每个标签监控一个文件：

| 操作 | 方式 |
|---|---|
| 新建监控项 | 工具栏「新建」或 `Ctrl+T` |
| 切换 | 点标签 / `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 关闭 | 标签上点中键、右键菜单、或 `Ctrl+W` |

**每个标签各有一套**：SSH 连接、显示内容、变更时间线、编辑状态、刷新间隔、滚动位置。
所以 A 文件配 2 秒、B 文件配 10 秒，切换时连间隔都跟着变；在 A 里改了一半切到 B，切回来修改还在。

### 只有当前标签在刷新

- **当前标签**：按你设的间隔正常轮询
- **其他标签**：只做「轻量探测」——每 20 秒读一次文件的 `stat`（大小 + 修改时间，几十字节），
  发现变了就在标签上打个 **● 红点**，**不下载内容、不写时间线**
- **切回该标签**：立即完整读一次，红点消失，显示最新内容

这样同时开十几个文件也不会各自持续拉取，开销只跟"你正在看的那个文件"有关。

### 新建 = 选文件，不用再填服务器

点「新建」或 `Ctrl+T`，直接弹出这台服务器上的文件浏览器：

- 默认就停在**当前文件所在目录**（正在看 `/var/log/app.log`，打开就是 `/var/log/`）
- 双击文件、或点中再按「选择」，即刻加一个标签
- 想建新文件，点底部「**新建文件...**」输个文件名（如 `notes.txt`）即可；
  文件在服务器上不存在时会问你要不要创建——适合拿它当几台机器之间的共享笔记
- 同一个文件不会重复开标签

「设置」里才是服务器连接（改完所有标签一起重连），外加当前文件的路径/间隔/编码。

## 快速开始

1. 双击桌面「远程文本监视器」
2. 第一次打开自动弹「连接设置」：

   | 字段 | 例子 | 说明 |
   |---|---|---|
   | 主机地址 | `192.168.1.100` | 服务器 IP 或域名 |
   | 端口 | `22` | SSH 端口 |
   | 用户名 | `root` | 登录账号 |
   | 认证方式 | 密码 / 私钥文件 | 私钥支持 OpenSSH 格式，可带口令 |
   | 远程文件 | `/var/log/app.log` | 要监视的文件；可点「浏览...」在服务器上选 |
   | 刷新间隔 | `2 秒` | 1~60 秒，先比对大小+修改时间，没变不下载 |
   | 文件编码 | 自动识别 | 自动区分 UTF-8 / GBK |

3. 点「测试连接」→ 成功后点「保存」。之后每次打开就直接看到内容。

### 行号栏

正文左侧常驻行号，滚动、缩放、编辑都会实时跟随：

- 关闭自动换行时，一个逻辑行对应一个行号
- **开启自动换行后，长行折行产生的续行不重复编号**（与代码编辑器一致），
  这样行号始终对应"第几条记录"，不会因为折行而错位
- 行号宽度按总行数自动调整（三位数、四位数…），不会在滚动时抖动

### 状态栏

| 位置 | 含义 |
|---|---|
| `● 已连接` | 绿=正常 / 红=连接失败（鼠标悬停看原因）/ 橙=`◀ 历史 09:40:39 · 点此返回实时` |
| `刷新 09:44:15` | 本地最后一次轮询的时间 |
| `更改 09:41:34` | **服务器上这个文件最后一次被修改的时间**（鼠标悬停看完整日期和编码） |
| `215 B · 5 行` | 文件大小和行数 |
| `▲ 新增 3 行` | 本次刷新新增了几行；`内容已变化` 表示不是纯追加（文件被重写/截断） |
| `★ 已收藏：xxx` | 刚才收藏成功的提示 |

### 工具栏

- **编辑**：切换编辑模式（`Ctrl+E`），见下文「编辑与写回」
- **保存**：编辑模式下才可用，写回服务器（`Ctrl+S`）
- **自动刷新**：按下（浅蓝）表示开启
- **跟随末尾**：新内容出现时自动滚到最后一行；关掉则你往上翻看时不会被强行拉回底部
- **自动换行**：长行折行；关掉保留横向滚动条（看日志通常关掉更整齐）
- **时间线**：显示/隐藏右侧面板
- **收藏**：把当前显示的内容存进收藏夹
- **收藏夹**：打开收藏列表
- **A- / A+**：调整正文字号

## 编辑与写回（可选）

默认是只读监视。需要改内容时：

1. 点工具栏 **「编辑」**（或 `Ctrl+E`）——正文变成可编辑、底色转淡黄
2. 直接改，改完点 **「保存」**（或 `Ctrl+S`）
3. 保存成功会自动退出编辑模式，状态栏显示 `✔ 已保存`

### 写回是安全的

保存时**不是**直接覆盖目标文件，而是：

```
上传到 .app.log.rtv-tmp-<时间戳>
  → 把原文件改名成 .app.log.rtv-bak-<时间戳>
  → 临时文件改名成目标文件
  → 删掉备份
```

任何一步失败都会回滚，**服务器上任何时刻都存在一份完整文件**，断网也不会写出半个文件。
写回时还会沿用原文件的编码（UTF-8 / UTF-8 BOM / GBK / UTF-16），中文不会变乱码。

### 冲突保护

编辑期间如果**另一台电脑也改了这个文件**：

- 正文不会被强行覆盖（你正在敲的内容保得住）
- 状态栏出现红色 `⚠ 远端已更新（保存时会提示冲突）`
- 点保存时弹对话框，**左右并排**对比「服务器当前版本」和「我的修改」（滚动联动），四个选择：

| 选择 | 结果 |
|---|---|
| **用我的覆盖** | 以你的版本为准（会二次确认，对方改动丢失） |
| **用服务器版本** | 放弃你的修改，载入服务器上的最新内容 |
| **我的另存为...** | 把你这版存成本地文件，仍留在编辑模式 |
| **取消** | 什么都不做，继续编辑 |

只有在你确认之后才会写入——默认绝不会静默覆盖别人的改动。

> ⚠️ 前提：这个文件应当**由你来编辑**。如果它是别的程序或别人持续写入的日志，
> 整文件保存会把对方这期间追加的内容抹掉。那种场景请只在只读模式下看，或提出「仅追加」需求。

### 时间线里的标记

- `+3行` —— 远端追加了 3 行
- `内容变化` —— 远端内容被改写
- `✎ 18321 3行` —— 由你在这台机器上编辑保存产生的，前面是当前 Windows 用户名
  （两台机器都开着时，一眼看出是谁存的）

## 三个新功能怎么用

### 1. 变更时间线（右侧面板）

每次检测到内容变化，就把当时的**完整快照**记一条，显示在右侧：

- `09:41:35  +3行` —— 那个时刻新增了 3 行
- `09:41:11  初始 2行` —— 程序第一次连上时文件的样子
- `内容变化` —— 文件被重写而不是追加

**只看最近 24 小时**，更早的自动清理；同时限制最多 2000 条 / 32 MB。

点击任一条 → 正文切到那一刻的内容（背景变淡黄、状态栏变橙），再点「返回实时」或按 `Esc` 回到最新。

> 新内容到来时，如果你正在看历史，正文**不会**被强制跳走 —— 只有点「返回实时」才回到最新。

### 2. 收藏

看到关键内容（比如订单失败现场、报警前后几行）：

1. 点「收藏」（或 `Ctrl + D`）
2. 名称默认是当前时间，可以直接改，比如「订单 1003 超时现场」
3. 确定 → 状态栏提示 `★ 已收藏`

收藏的内容**不会过期**，随时可以在收藏夹里找回来。

### 3. 收藏夹

点「收藏夹」（或 `Ctrl + B`）：

- 左边列表：名称 / 收藏时间 / 行数
- 右边预览：完整内容
- 底部：`在主窗口查看`、`重命名`、`删除`、`另存为...`

## 数据存在哪

```
%APPDATA%\RemoteTxtViewer\
├─ sessions.ini               [server] 全局服务器 + [file.N] 各文件设置（密码 DPAPI 加密）
├─ history\                   变更时间线，按监控项分目录
│   └─ <会话id>\              会话id = SHA256(主机|用户|路径) 前 16 位
│       ├─ index.tsv          索引
│       └─ c_<时间戳>.txt     每次变更的完整快照
└─ favorites\                 收藏夹（全局共享，不会自动清理）
    ├─ index.tsv              索引（名称、时间、来源、行数）
    └─ f_<时间戳>.txt         收藏的完整内容
```

> 从旧版本升级时会自动迁移：`config.ini` 变成一个监控项；
> 旧的多会话配置（每个标签各自带服务器信息）会取第一个的服务器作为全局，
> 其余按文件拆开。旧 `history\` 数据也会搬到对应会话目录下，不用手动处理。

- **密码和私钥口令用 Windows DPAPI 加密**，只有当前 Windows 用户 + 这台电脑能解开。
  拷给别人、同步到网盘、换电脑都解不开。代价是换电脑/换账号要重填一次密码。
- 历史快照 24 小时自动清理；收藏永久保留（想删就在收藏夹里删）。
- 想彻底清空：关掉程序后删掉对应目录即可。

## 安全：主机指纹校验

第一次连接某台服务器时，程序会记下它的 SSH 主机密钥指纹（SHA256）存进 `config.ini`。
**以后每次连接都会比对**：

- 一致 → 正常连接，无感知
- 不一致 → 拒绝连接，状态栏红字提示：
  `服务器指纹不符！已记录 a1b2…，本次 c3d4… —— 可能是中间人攻击；若服务器重装过系统，请在设置里点「重置主机指纹」`

这是为了防止内网里有人冒充你的服务器（ARP/DNS 欺骗等中间人攻击），作用等同于 `ssh` 首次连接时问的 `yes/no`。

**什么时候需要点「重置主机指纹」**（设置对话框左下角）：
- 服务器确实重装过系统
- 服务器换了 SSH 主机密钥
- 确认服务器 IP 被重新分配给另一台机器

其他情况看到"指纹不符"请先当成安全事件处理，别急着重置。

## 常见状态与处理

| 状态栏提示 | 处理 |
|---|---|
| 认证失败 | 用户名/密码错了，或私钥不对 |
| 远程路径不存在 | 路径写错，用「浏览...」重新选 |
| 连接超时 / 网络不可达 | 没连上服务器所在网络（VPN？）或防火墙拦了端口 |
| 端口被拒绝 | SSH 服务没启动，或端口不是 22 |
| 权限不足 | 该账号无权读这个文件 |
| 服务器指纹不符 | 见上一节 |

断线不会卡死：每次轮询都会自动重连，服务器恢复后状态栏自己变回绿色。

## 源码与重新编译

```

├─ RemoteTxtViewer.exe     编译产物（单文件，桌面快捷方式指向它）

│   ├─ FavoritesStore.cs   收藏夹存储
```
